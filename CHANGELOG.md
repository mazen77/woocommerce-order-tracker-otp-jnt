# Changelog

## 3.4.0 - 2026-09-29

- Prepared the plugin for public GitHub distribution.
- Added author attribution for **Mazen Bassiso** and **fa7ma.com**.
- Renamed the public-facing plugin title for easier WooCommerce/order-tracking discovery.
- Fixed undefined payment-method variables in the My Account and admin panels.
- Fixed malformed HTML style output in the My Account panel.
- Improved the admin meta-box callback for HPOS order screens.
- Declared WooCommerce HPOS compatibility.
- Added request throttling for OTP starts and verification attempts.
- Prevented OTP sends to email addresses/phone numbers not associated with an order.
- Made verification fetch tokens single-use.
- Added the `mazen_order_tracker_tracking_meta_keys` developer filter.
- Synchronized CSS/JS asset versions with the plugin version.
- Added GitHub documentation, contribution/security guidance, issue templates, and PHP lint CI.
