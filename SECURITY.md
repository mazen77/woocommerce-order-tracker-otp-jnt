# Security Policy

Please do not publish exploitable security issues in a public GitHub issue.

For security reports, contact the maintainer through https://fa7ma.com and include enough detail to reproduce the issue without including real customer information or credentials.

## Sensitive data

Never include the following in bug reports or pull requests:

- Real customer names, emails, phone numbers, or addresses
- WooCommerce order exports
- SMS API keys or secrets
- WordPress salts/passwords
- Production access credentials
